Exedra Linux 0.1.0

Дистрибутив для тех, кто хочет простоты в изменении установленных приложений и стабильности: ядро и systemd из upstream Arch, свой пакетный менеджер venim и рецепты VenimBuild.

Скачать ISO Как ставить пакеты

Две редакции: Core (CLI) и Desktop (KDE Plasma). Гибридный ISO: BIOS + UEFI.

Чем отличается

Три вещи, ради которых проект существует.

Приложения просто менять

Каждое приложение — отдельное дерево в /venim/packages/имя/версия/: видно все файлы, легко поправить, проверить (verify, doctor) и откатить.

Стабильность

Версионные деревья не смешиваются: обновление не трогает работающее, сломанное чинится пересозданием симлинков (repair).

VenimBuild

Рецепты *.vnb — короткий DSL: source/binary, depends, install-команды. Свой репозиторий из 200+ рецептов.

FAQ

UEFI не видит флешку. Что делать?

Записывайте образ побайтово на устройство, не в раздел: dd if=Exedra-*.iso of=/dev/sdX bs=4M oflag=sync. Проверьте таблицу разделов после записи — должен быть виден EFI-раздел.

Secure Boot ругается. Это нормально?

Да. Загрузчик подписан собственным ключом Exedra, стоковая прошивка его не знает. Выключите Secure Boot в UEFI Setup либо добавьте наш ключ (подробности — в docs/secureboot.md репозитория).

Не работает WiFi на live-сессии

Прошивки Intel/Realtek/MediaTek/Atheros/Broadcom и драйверы rtw89, rtw88, ath11k/ath12k, mt76/mt7925 в образе есть. Проверьте rfkill list (частый виновник — hard block клавишей) и вывод dmesg | grep -i firmware. Исключение: Broadcom-wl (проприетарный DKMS) — только вручную после установки.

Как поменять файлы установленного приложения?

Всё лежит открыто в /venim/packages/имя/версия/, в системе — только симлинки. Правишь дерево или рецепт, переустанавливаешь, проверяешь venim verify имя. Сломал ссылки — чинит venim repair.

Чем ставить программы?

Пакетником venim: venim install firefox. Рецепты лежат в каталоге packages/ и в онлайн-репозитории на 200+ рецептов. Подробности — на странице пакетов.

На чём написан venim?

На C++17 (SQLite, libcurl, OpenSSL). Начиная с 0.1.0 интерпретатор не нужен: /usr/bin/venim — нативный бинарник.

Есть ли 32-битная версия?

Нет, только x86_64 (BIOS и UEFI).
