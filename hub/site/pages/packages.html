Пакеты venim

Смотри, как всё устроено: каждая программа живёт в своей папочке /venim/packages/имя/версия/, а в систему торчат только симлинки. Поэтому всё так легко ковырять.

Команды Формат рецепта

Команды, которых хватит

venim install firefox — поставить по имени

venim install ./foo.vnb — поставить из файлика с рецептом

venim install https://host/foo.vnb — поставить прямо по ссылке

venim --repo https://host/tree install yt-dlp — ставить из чужого (или своего) онлайн-репозитория

venim remove firefox — снести (сначала проверит, что пакет никому не нужен, и откажет, если нужен)

venim list, venim info firefox, venim verify firefox, venim doctor — посмотреть, разузнать, проверить, полечить

venim install --no-check ... — ставить, не сверяя sha256 (или VENIM_NO_CHECK=1 раз и навсегда)

Рецепт VenimBuild

Это весь рецепт установки AppImage. Серьёзно, вот прям весь:

package "obsidian" {

  version = "1.10.7"

  binary { url = "https://github.com/.../Obsidian-1.10.7.AppImage" }

  install {

    command "mkdir -p ${destdir}/opt/obsidian ${destdir}/bin"

    command "cp ${srcdir}/Obsidian-1.10.7.AppImage ${destdir}/opt/obsidian/obsidian.AppImage"

    command "ln -sf ../opt/obsidian/obsidian.AppImage ${destdir}/bin/obsidian"

  }

}

Пара правил, и всё: раскладка сразу финальная (bin/, opt/), ссылки только относительные. Полная спека — в репозитории рецептов.

Онлайн-репозиторий

У нас уже есть дерево на 300+ рецептов: браузеры, редакторы, дев-инструменты, языки, сеть, игры. Лежит на гитхабе, подключается одной строкой.

venim --repo https://... update — скачать индекс

venim --repo https://... search rust — поискать там

Индекс — это обычный index.json в корне дерева, делается командой venim index ./моё-дерево. Так что свой репозиторий собирается так же, ничего хитрого.
