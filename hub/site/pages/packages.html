Пакеты venim

Каждый пакет живёт изолированно в /venim/packages/имя/версия/, в систему попадает относительными симлинками.

Команды Формат рецепта

Команды

venim install firefox — поставить из репозитория

venim install ./foo.vnb — поставить из локального файла

venim install https://host/foo.vnb — поставить по URL

venim --repo https://host/tree install yt-dlp — из онлайн-репозитория

venim remove firefox — убрать (проверяет обратные зависимости)

venim list, venim info firefox, venim verify firefox, venim doctor

venim install --no-check ... — пропустить проверку sha256 (или VENIM_NO_CHECK=1)

Рецепт VenimBuild

Короткий DSL. Этот рецепт ставит готовый AppImage:

package "obsidian" {

  version = "1.10.7"

  binary { url = "https://github.com/.../Obsidian-1.10.7.AppImage" }

  install {

    command "mkdir -p ${destdir}/opt/obsidian ${destdir}/bin"

    command "cp ${srcdir}/Obsidian-1.10.7.AppImage ${destdir}/opt/obsidian/obsidian.AppImage"

    command "ln -sf ../opt/obsidian/obsidian.AppImage ${destdir}/bin/obsidian"

  }

}

Правила: финальная раскладка сразу (bin/, opt/), ссылки только относительные. Полная спецификация — в репозитории рецептов.

Онлайн-репозиторий

200+ рецептов: браузеры, редакторы, dev-инструменты, языки, сеть, игры, AI, бэкапы.

venim --repo https://... update — обновить индекс

venim --repo https://... search rust — поиск

Индекс — обычный index.json в корне дерева, генерируется командой venim index ./tree. Свой репозиторий собирается так же.
