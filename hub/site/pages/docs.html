Документация

Тут всё про пакетник: как ставить, как удалять, как проверять — и как писать свои рецепты, если чего-то не хватает.

Пользование пакетником

Запомни одну вещь: каждый пакет — отдельная папка /venim/packages/имя/версия/, а в системе только симлинки на неё. Отсюда всё остальное.

venim install firefox — ставит по имени

venim install ./foo.vnb — ставит из файла рецепта у тебя на диске

venim install https://host/foo.vnb — ставит прямо по ссылке из интернета

venim remove firefox — сносит (если пакет кому-то нужен — честно откажет, а не сломает молча)

venim list — что вообще стоит; venim info firefox — подробности про пакет

venim verify firefox — сверяет файлы с базой, скажет, что битое; venim doctor — ищет битое по всей системе

venim repair — пересоздаёт все симлинки разом. Накосячил со ссылками — одна команда, и всё снова хорошо

venim search rust — поиск; venim upgrade — переустановить то, что изменилось в рецептах

Онлайн-репозиторий

Репозиторий — это просто дерево рецептов + файлик index.json в корне. Наш общий на 300+ рецептов уже лежит на гитхабе.

venim --repo https://host/tree update — скачать свежий индекс

venim --repo https://host/tree search yt — поискать в нём

venim --repo https://host/tree --no-check install yt-dlp — поставить оттуда

Надоело каждый раз писать --repo? Пропиши VENIM_REPO=https://host/tree в окружение — и работай как обычно.

Свой индекс делается так: venim index ./моё-дерево. Заодно проверяет, что все рецепты вообще парсятся.

Как написать свой рецепт

Файлик имя.vnb. Хэши — по желанию: есть строчка sha256 — проверится, нет — поставится как есть. Не хочешь проверок вообще — ставь с --no-check.

package "myapp" {

  version = "1.0"

  binary { url = "https://host/myapp.AppImage" }

  install {

    command "mkdir -p ${destdir}/opt/myapp ${destdir}/bin"

    command "cp ${srcdir}/myapp.AppImage ${destdir}/opt/myapp/myapp.AppImage"

    command "ln -sf ../opt/myapp/myapp.AppImage ${destdir}/bin/myapp"

  }

}

Три правила, всё: раскладка сразу финальная (bin/, opt/), ссылки только относительные (../opt/..., иначе сломается). Переменные: ${srcdir} — куда скачалось, ${destdir} — куда кладём, плюс ${name} и ${version}. Надо собрать из исходников — есть блоки source, build, prepare и check, работают так же.

Как менять установленное

Ради этого всё и затевалось: ничего нигде не размазано.

Найти файлы

Всё приложение целиком — в /venim/packages/имя/версия/. А что куда ссылается — расскажет venim info имя.

Поправить

Правишь дерево или рецепт и переустанавливаешь. Потом venim verify имя — убедиться, что всё на месте.

Починить

Если что-то разъехалось — venim repair пересоздаст все симлинки разом. Быстро и не больно.
