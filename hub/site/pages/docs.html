Документация

Пакетник venim: установка, удаление, проверка — и как писать свои рецепты.

Пользование пакетником

Каждый пакет — отдельное дерево /venim/packages/имя/версия/, в системе только симлинки.

venim install firefox — поставить по имени

venim install ./foo.vnb — поставить из файла рецепта

venim install https://host/foo.vnb — поставить по URL

venim remove firefox — убрать (проверяет, что пакет никому не нужен)

venim list — что установлено; venim info firefox — детали

venim verify firefox — сверить файлы с базой; venim doctor — найти битое

venim repair — пересоздать все симлинки (лечит кривые ссылки разом)

venim search rust — поиск; venim upgrade — переустановить изменившиеся

Онлайн-репозиторий

Дерево рецептов + index.json в корне. Готовый репозиторий на 300+ рецептов идёт вместе с проектом.

venim --repo https://host/tree update — скачать индекс

venim --repo https://host/tree search yt — искать в нём

venim --repo https://host/tree --no-check install yt-dlp — ставить оттуда

Свой индекс: venim index ./моё-дерево — заодно проверяет, что все рецепты парсятся.

Как написать рецепт

Файл имя.vnb. Хэши опциональны: есть — проверяются, нет — ставится как есть (--no-check отключает проверку вообще).

package "myapp" {

  version = "1.0"

  description = "что это"

  binary { url = "https://host/myapp.AppImage" }

  install {

    command "mkdir -p ${destdir}/opt/myapp ${destdir}/bin"

    command "cp ${srcdir}/myapp.AppImage ${destdir}/opt/myapp/myapp.AppImage"

    command "ln -sf ../opt/myapp/myapp.AppImage ${destdir}/bin/myapp"

  }

}

Правила простые: раскладка сразу финальная (bin/, opt/), ссылки только относительные. Переменные: ${srcdir} (скачанное), ${destdir} (куда кладём), ${name}, ${version}. Для сборки из исходников — блоки source, build, prepare, check.

Как менять установленное

В этом смысл Exedra: ничего не размазано по системе.

Найти файлы

Всё приложение — в /venim/packages/имя/версия/. Что куда ссылается — покажет venim info имя.

Поправить

Правишь дерево или рецепт и переустанавливаешь. Проверить — venim verify имя.

Починить

Сломал ссылки — venim repair пересоздаст их для всех пакетов разом.
